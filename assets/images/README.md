## Gallery

- `work-01.jpg` through `work-12.jpg` — portfolio sets

Use sharp, well-lit photos of Naledi's actual work. Vertical 4:5 images are ideal for the main portfolio; square or 4:5 images work well for detail shots.

The website already contains the gallery data, filters and lightbox. Adding or replacing a photo here is enough to update the visual portfolio without redesigning the site.
