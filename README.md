# 💎 About the Project

**Nails by Naledi** is a professional beauty portfolio website created to establish a strong digital presence for a nail-art business.

The website combines modern frontend development with a luxury editorial-inspired design to create a visual experience that reflects the brand's focus on:

- Beauty
- Detail
- Confidence
- Creativity
- Personal expression

The portfolio allows potential clients to explore Naledi's work, learn about her services, view pricing, and contact her directly to make an appointment.

---

# 🎯 Project Objectives

The main objectives of the project are to:

- Create a professional online presence for Nails by Naledi
- Showcase real nail-art photography
- Provide an attractive and easy-to-use portfolio
- Allow clients to browse different nail styles
- Provide clear service information
- Display pricing
- Provide direct WhatsApp booking
- Link visitors to social media
- Provide a professional mobile experience
- Create a foundation for future business features

# 🖼️ Portfolio Gallery

The gallery showcases real nail-art work.

Visitors can filter designs according to different categories.

### Gallery Categories

- French
- Nude
- Pink
- Nail Art
- Long Nails
- Pedicure

The gallery also includes an interactive image viewer/lightbox.

Users can:

- Open individual images
- View larger versions
- Navigate between images
- Close the image viewer
- Browse the portfolio without leaving the page

---

# 💎 Long Nails Collection

The portfolio specifically separates long nail designs so clients looking for longer styles can easily find them.

Examples include:

- Long French Almond
- French Stiletto
- Long statement designs

This helps clients quickly identify the style they are interested in.

---

# 💰 Pricing

The website includes a dedicated pricing section where clients can view available services and their corresponding prices.

The pricing layout is designed to be:

- Easy to understand
- Mobile friendly
- Visually clean
- Consistent with the brand

Prices can easily be updated directly within the website as the business grows.
